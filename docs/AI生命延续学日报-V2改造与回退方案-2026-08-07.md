# AI 生命延续学日报 V2 改造与回退方案

## 文档状态

- 执行日期：2026-08-07
- 执行对象：仅“AI 生命延续学日报”普通日报
- 前端安全分支：`codex/bioai-daily-v2-20260807-frontend`
- 后端安全分支：`codex/bioai-daily-v2-20260807-backend`
- 当前决定：继续向前修复一次，不整体回退
- 发布状态：先完成离线样稿和四视口验收；未获确认前不推送、不部署

## 一、问题判断

当前版本不是单一的“样式不好”，而是四个问题叠加：

1. 根路径由原来的最新日报入口变成了栏目落地页，增加了一次无价值点击。
2. 内容合同把研究类型、物种、样本、证据等级、应用距离等字段全部平铺，医学安全性提高了，但文章被写成审稿表，普通读者难以连续阅读。
3. 图片链路只有“允许模型使用候选中已有图片”和“删除不合规图片”，没有图片发现、可用性验证、来源绑定和无图时的信息图兜底，因而最新日报变成纯文本。
4. 前端建立了独立的 BioAI 卡片体系，没有完整继承 AI 日报已经验证的字体角色、标题层级、来源链接、图注、日夜主题和移动端规则。

旧版文章更有阅读感、图片更多，但也存在图片重复、图注模糊、标题带链接、二手来源冒充研究原文、趋势预测和 FAQ 凑篇幅等问题。因此不适合整体回退。

## 二、总策略

采用“保留安全底座、恢复阅读体验、重建媒体链路”的前进方案：

- 保留：医学禁区、研究类型识别、证据分级、多维去重、失败稿不入记忆、任务隔离和人工复核门槛。
- 改掉：首页落地页、十一字段平铺、纯文本页面、独立漂移的字体和卡片 UI。
- 借鉴：AI 日报成熟的字体角色、标题节奏、证据链接、图片图注、日夜主题和移动端约束。
- 不复制：AI 日报的赛博装饰、夸张发光效果和与生命科学不相符的情绪表达。

若本轮离线 V2 仍不能达到验收标准，则选择性恢复旧版的叙事结构和视觉体验，同时继续保留现有医学安全、来源校验、去重和任务隔离；禁止用破坏性 reset/rebase 覆盖用户工作区。

## 三、执行顺序

### 阶段 1：安全基线与方案落盘

1. 以最新远端稳定提交创建 D 盘独立 worktree。
2. 核对分支、remote、dirty 和基线提交。
3. 先提交本方案，后续每一阶段单独形成可回滚提交。

### 阶段 2：恢复“打开即最新日报”

1. 根路径 `/` 使用 Hugo 模板动态查找普通日报最新日期页。
2. 输出 `canonical`、`noindex,follow`、脚本跳转、meta refresh 和无脚本备用链接。
3. 日期页继续作为唯一完整 canonical；月目录负责归档。
4. 删除普通日报定时任务和手动生成链路对 `content/cn/_index.md` 的每日覆盖行为。
5. 两个商机栏目自己的入口和内容路径不变。

### 阶段 3：重做内容合同与来源门槛

每期保留 5–8 个真正重要的信号。模型先提交结构化、可校验的事实，再渲染为适合读者阅读的正文；不得把全部审稿字段平铺成表单。

每条对读者固定呈现：

1. 一句话结论。
2. 发生了什么。
3. 为什么值得关注。
4. 目前不能得出什么结论。
5. 一条可点击的一手来源；必要时补充发现来源。

研究类型、物种、样本量、发表状态、冲突信息、证据等级和应用距离继续作为确定性校验字段，但合并进简洁的“证据卡/证据说明”，不要求每项都以独立大段出现。

候选分池目标：

- 论文与研究：2–3 条。
- 产品、工具或开源项目：1 条。
- 行业、监管或公共机构：1 条（有合格素材时）。
- 趣味信号：可选；没有合格素材则省略。

硬门槛：

- 生物医学研究进入主榜必须有论文、期刊、临床注册或机构原文。
- 二手报道可作为发现来源，不能单独证明人体疗效。
- 预印本、动物实验、观察性研究和小样本必须显式标注。
- 禁止诊断、治疗、药物、逆龄或寿命承诺。
- 7 天内按 canonical URL、DOI、临床试验号、GitHub canonical repo 和核心事件实体去重。
- 未通过发布校验的稿件不得写入去重记忆。

文章总长度目标为约 3500–5500 个中文字符；只解释 2–4 个真正影响理解的术语，不批量生成 FAQ、趋势预测或商店广告。

### 阶段 4：重建图片与信息图链路

1. 从候选正文、Open Graph 元数据和项目官方页面提取候选图片。
2. 校验 URL、响应状态、媒体类型、尺寸/可读性、候选来源归属和重复度。
3. 每期优先使用 2–4 张有信息价值的图片，跨来源去重；每张必须有准确 alt、图注和来源链接。
4. 论文受版权限制的整图不抓取；无法确认授权或来源的图片不使用。
5. 没有合格外部图片时，由前端根据已验证的证据字段绘制确定性的 SVG 证据概览，不让页面退化为纯文字，也不生成虚假实验图。
6. 图片失败只能降级到信息图或少图模式，不能阻塞普通日报发布。

### 阶段 5：融合 AI 日报的视觉系统

采用“同一家族、不同栏目”的设计：

- 继承 AI 日报的中文速读字体、英文/数字显示字体、代码短标识等宽字体及其许可文件。
- 继承清楚的 masthead、标题级别、蓝色来源链接、关键词强调、图片条纹/图注、表格和移动端换行规则。
- BioAI 日间以可信的深蓝、青绿和暖灰为主；夜间保持现代研究感，但降低霓虹和发光。
- 去掉大面积嵌套卡片、左侧装饰竖条和“字段表格感”。首屏直接显示今日判断、证据概览、应用距离和第一条内容。
- 手机正文不低于 16px；中英文、基因/蛋白名、DOI、样本量、百分比和时间跨度保持一致视觉重量。
- 动效只用于状态变化和链接反馈，并遵循 `prefers-reduced-motion`。

### 阶段 6：离线验收

发布前必须同时通过：

1. 后端单元测试与新增的内容合同、来源、去重、媒体和任务隔离测试。
2. Hugo 构建、canonical/schema/robots/sitemap 检查。
3. 根路径动态指向最新日期页，不能硬编码日期。
4. 最新一期离线 dry-run 逐条核对关键医学事实和来源。
5. 桌面与 390px 手机的日间/夜间四视口截图。
6. 英文论文名、基因名、样本量、百分比和 DOI 的真实段落字体检查。
7. 两个商机入口和 `scheduledBlog.js` 回归测试。

只有离线样稿、截图、测试和差异经人工确认后，才进入推送和 Cloudflare 部署。

## 五、任务隔离

- 普通日报、AI 生命延续学商机、AI 生命延续学资讯商机项目保持独立的生成、校验、发布状态。
- 三者可复用只读抓取缓存，但不得复用成稿、失败状态或去重写入事务。
- 普通日报成功与否不得被任一商机栏目阻塞，商机失败也不得覆盖普通日报。
- `scheduledBlog.js` 只做回归检查，本轮不修改、不触发正式博客生成。

## 六、验收与回退点

每一阶段创建独立本地提交，形成以下回退点：

1. 方案文档基线。
2. 最新日期直达。
3. 内容、来源与媒体链路。
4. 前端视觉融合。
5. 测试和离线样稿。

最终硬性验收：

- 打开站点即进入最新已发布的普通日报日期页。
- 每期 5–8 条，读者先看到结论和意义，审稿字段不再主导阅读。
- 不把预印本、动物实验或相关性研究写成人体疗效。
- 关键研究有一手来源；图片有来源、alt、图注且不盗用受限整图。
- 正常素材条件下有 2–4 张有效图片；无图时有事实驱动的信息图兜底。
- 日夜、桌面和手机均达到 AI 日报的可读性基线，同时保持生命科学的可信与克制。
- 普通日报不侵占商机结构，不改坏两个商机或个人博客任务。
- `robots`、`sitemap`、`canonical` 使用 `news.aibioo.cn`。

若 V2 离线验收仍不通过，恢复旧版的叙事结构和视觉组件，但保留本轮前已存在以及本轮增强的医学安全、来源校验、去重、媒体来源绑定和任务隔离。任何回退均通过独立提交的反向变更完成，不覆盖原始本地工作区。
