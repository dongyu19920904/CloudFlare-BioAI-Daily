# 普通日报通俗化写作修正

日期：2026-10-17。只修改普通日报，不改变信息源、过滤标准、商业栏目、页面样式、Cron、模型线路和 Secrets。

## 诊断

上一轮已解决栏目、独立导语、引用标签和阅读样式，但写作提示词仍把作者定位为证据编辑，要求方法、对象、数据和限制，却没有明确普通读者的术语负担。今天的原稿因此保留大量分子名、试验代号和指标，摘要也成了第二份研究摘要。仅规定字数并不能保证读者看得懂。

## Diff

- `src/prompt/summarizationPromptStepZero.js`：明确面向没有医学背景的读者；先说发生了什么和用途，再简短说明应用距离。每条只保留理解所需的 1-2 个专名，数字通常一组、最多两组，删次要指标和方法链。必要术语当场解释，不额外堆中英全称或加粗。保留来源内嵌、动物与人体、试验阶段、阴性结果和主要研究限制。
- 同文件导出短写作提醒 `getBioDailyReadabilityReminder`，不生成示例新闻、不机械截断正文。
- `src/handlers/scheduled.js`、`src/handlers/genAIContent.js`：在素材末尾追加同一提醒，避免长材料冲淡系统规则；将原有第二次调用从“仅摘要”调整为“全文通俗化审稿 + 摘要”，仍是两次调用，不额外增加第三次。第二次输出全文会增加相对原短摘要的输出 token，不能说完全不增加用量。
- `src/prompt/summarizationPromptStepThree.js`：三句摘要面向普通读者，合计最多一组数字，不列基因、蛋白、药物代号和试验编号，不硬凑宏大行业趋势，也不要求普通人核查分子通路。
- 同文件新增专用全文编辑提示词；解析器要求返回完整正文、三句摘要和同一来源 URL 集合。缺正文或来源被更换/省略时在写仓库前失败，不把三句话摘要当成整篇文章。保留内部摘要代码围栏，修正旧清理函数会只提取第一个围栏内容的风险。
- `.github/workflows/manual-trigger-worker.yml`：失败的 dry-run 也保留限期诊断产物，不把响应正文输出到公开日志。
- 复用博客链路已有的 `ANTHROPIC_NATIVE_SYSTEM_PROMPT` 开关，仅在普通日报调用时传递原生系统指令，避免与材料混在同一条用户消息里。非流式备用请求也尊重此显式开关；其他未启用开关的调用保持原有兼容行为。
- `tests/dailyEditorialPrompt.test.mjs`：新增三组测试，检查可读性规则、摘要要求，以及手动/定时路径都在素材末尾追加提醒。
