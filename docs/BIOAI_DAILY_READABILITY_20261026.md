## 确认问题与最小修复

- 旧规则反复要求每条 150-230 汉字、4-6 句、解释 1-3 个概念；实际稿件仍超过该范围，机制和次要指标堆积。改为共用短资讯约定：TOP 通常 110-180 汉字、3-4 句，一个核心概念、一项主要发现，必要临床限定可到 220 字。保留样本、时间、阴性结果与证据边界，不截断正文，不新增第三次模型润色。
- 来源正文的链接在转成纯文本输入时会丢失，旧媒体恢复只能使用 RSS 已给的第一张图片。普通日报现在另外保留原始 HTML，只对已引用素材中明确链接的可信机构文章补查图片元数据。最多 3 次 GET，总期限 6 秒，单次最长 3 秒、350 KB，禁止自动重定向；不爬聚合站、不猜 URL、不读取健康资料、不执行网页内容。仅支持代码中列明的 MIT News、MIT Picower、GEN、ScienceDaily 文章路径，失败降级为无图。
- 图片恢复按已引用的同一来源匹配，每条至多补一张、全篇补图预算至多四张，跳过 FAQ 和重复图片。支持原始 HTML 懒加载图片，排除视频文件、明显 Logo 和追踪像素；不更改共用的个人博客媒体策略。
- 每次正常生成记录 `Daily readability`（均长及超过 220 汉字的条目序号）和 `Source image metadata`（请求/新增/失败数）。这些是诊断，不是医学结论，也不以删证据或停止正常出版强行达成字数。模型未来仍可能偏离风格，应以实际稿件和日志复核，不能把固定 mock 通过当成真实模型稳定性保证。
